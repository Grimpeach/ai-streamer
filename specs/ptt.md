# Спецификация: Push-to-Talk и STT (Фаза 3)

Реализация: `src/modules/ptt/hotkey.py`, запись — `recorder.py`,
распознавание — `stt.py`. Клавиша и модель берутся из `PTTSettings` /
`STTSettings` (`PTT__HOTKEY`, `STT__MODEL`).

## 1. Абсолютный приоритет

Требование `.cursorrules` п.4 и [architecture.md](architecture.md): нажатие
PTT **мгновенно** отменяет текущую генерацию LLM/TTS. Это важнее, чем
успеть записать первый слог.

Порядок в колбэке `keyboard` (чужой поток):

1. `EventBus.preempt(reason="ptt")` через `call_soon_threadsafe` — первым.
   Сам `preempt` трогает asyncio-задачи, поэтому выполняется уже в event loop,
   но ставится в очередь loop'а раньше любой другой работы этого нажатия.
2. Флаг захвата в уже открытом потоке микрофона. Открытие устройства на
   нажатие опоздало бы на десятки миллисекунд и съело бы начало реплики.
3. После отпускания — расшифровка в отдельном потоке и публикация
   `ptt.host_speech` с приоритетом 1 (`EventPriority.INTERRUPT`).

Событие `ptt.pressed` публикуется с `preemptive=False`: отмена уже выполнена
прямым вызовом `preempt`. Повторный preempt внутри `publish()` сбил бы токены
обработчиков, которые только что стартовали на это нажатие (сброс очереди TTS).

`ptt.host_speech` остаётся preemptive: пока шла расшифровка, в очередь мог
успеть встать новый чат и запустить LLM — реплика хоста должна его перебить.

## 2. Неблокирующий event loop

| Операция | Где выполняется |
|---|---|
| Хук клавиши | поток библиотеки `keyboard` |
| Аудио-колбэк PortAudio | поток `sounddevice` |
| Открытие/закрытие микрофона | `asyncio.to_thread` |
| Загрузка весов Whisper и инференс | `ThreadPoolExecutor(max_workers=1)` |
| `preempt` и публикация событий | event loop |

Модель faster-whisper не потокобезопасна, поэтому пул ровно из одного потока.
Параллельные реплики всё равно упёрлись бы в одну GPU.

## 3. Запись

Поток микрофона открывается при `start()` и живёт весь стрим. В кольцевом
буфере хранятся последние `max_utterance_s + preroll_ms`. Нажатие отступает
назад на `preroll_ms` (по умолчанию 300 мс): человек начинает говорить чуть
раньше, чем дожимает клавишу.

Случайный тап короче `min_utterance_s` прерывает генерацию, но в STT не идёт.
Затянувшаяся реплика обрезается с конца: последние слова важнее начала.

## 4. STT

CTranslate2 на Windows ищет ``cublas64_12.dll`` в системных путях, а не в
``torch/lib``, где этот файл уже лежит вместе с PyTorch. Перед загрузкой
модели `ensure_windows_cuda_dlls()` регистрирует эти каталоги через
``os.add_dll_directory``. Прогрев гоняет короткий тон с ``vad_filter=False``:
тишина отсекается VAD, энкодер не вызывается, и отсутствие cuBLAS всплывает
только на первой живой реплике.

Живая реплика включает Silero VAD и требует пакет ``onnxruntime``
(``import onnxruntime``). Если его нет, STT выключает VAD и всё равно
расшифровывает — PTT не должен падать. Установка: ``pip install onnxruntime``.

Если CUDA-библиотеки всё равно не грузятся, STT переключается на CPU (int8),
а не роняет PTT. Это запасной путь: целевая машина — RTX 4080 / CUDA 12.

* `beam_size=1` — greedy: реплики короткие, beam search не окупает задержку.
* `task=translate` — Whisper отдаёт **английский** текст, даже если хост говорит
  по-русски (`STT__TASK=transcribe` вернёт язык источника).
* `language` пустой — автоопределение языка речи; можно задать `STT__LANGUAGE=ru`.
* `condition_on_previous_text=false` — иначе Whisper дописывает прошлую фразу.
* сегменты с `no_speech_prob` выше порога отбрасываются по одному: тихий хвост
  не должен выкидывать уже сказанные слова.
* прогрев гоняет короткий тон без VAD, чтобы сразу проверить cuBLAS.

Устаревшая расшифровка (хост нажал PTT снова, пока считался прошлый кусок)
не публикуется: номер реплики сравнивается до и после инференса.

## 5. Конфигурация

| Переменная | Назначение |
|---|---|
| `PTT__HOTKEY` / `PTT_HOTKEY` | глобальная клавиша, по умолчанию `f13` |
| `STT__MODEL` / `STT_MODEL` | имя или путь модели faster-whisper |
| `STT__TASK` / `STT_TASK` | `translate` (английский текст) или `transcribe` |
| `STT__LANGUAGE` / `STT_LANGUAGE` | подсказка языка речи; пусто — авто |
| `PTT__INPUT_DEVICE` | устройство sounddevice; пусто — системное |
| `STT__DEVICE` | `cuda` или `cpu` |

На Windows библиотека `keyboard` требует прав администратора на глобальный
перехват. Если хук не встаёт, модуль откатывает загрузку STT и закрывает
микрофон — не оставляем 1 ГБ VRAM занятым впустую.

## 6. Проверка

`tests/test_ptt.py` подменяет микрофон и Whisper, но оставляет настоящие
`asyncio.to_thread` и пул STT — именно они проверяют, что event loop не
замирает. Покрыто: мгновенный preempt, приоритет 1, игнор автоповтора,
короткое нажатие, пустой и устаревший транскрипт, pre-roll, неблокирующесть.

Живая проверка без LLM и TTS (скачает веса модели при первом запуске):

```powershell
python main.py --ptt-only
```
